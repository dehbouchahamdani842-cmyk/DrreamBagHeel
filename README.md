DrreamBagHeel est un site web de vente en ligne de chaussures et de sacs développé à l'aide des technologies HTML, CSS et JavaScript.
Il offre une interface moderne et intuitive permettant aux utilisateurs de découvrir les produits et d'effectuer leurs achats facilement.
La page d'accueil (Index) présente une description de notre collection, les informations de contact ainsi que les adresses de nos magasins afin de faciliter la communication avec les clients.
Elle permet également de découvrir l'univers et les valeurs de la marque.
La page Collection permet de parcourir les différents modèles de chaussures et de sacs disponibles.Les utilisateurs peuvent filtrer les produits en choisissant la catégorie souhaitée (chaussures ou sacs) afin de trouver plus rapidement les articles qui les intéressent.Ils peuvent également sélectionner leur devise entre le Dinar Algérien (DA) et l'Euro (€). 
La devise sélectionnée est conservée et appliquée durant tout le processus d'achat afin d'assurer une expérience cohérente.
Le site dispose également d'une fonctionnalité Favoris, représentée par un bouton permettant aux utilisateurs de sélectionner et de sauvegarder les articles qui leur plaisent afin de les retrouver facilement lors de leurs prochaines visites.
En plus des favoris, le site intègre un système de panier d'achat permettant d'ajouter, modifier ou supprimer des articles avant la validation de la commande. 
Lors du paiement, l'utilisateur peut choisir entre une carte bancaire algérienne (CIB/Edahabia) ou une carte Visa pour finaliser son achat.
Ce projet met en pratique les concepts fondamentaux du développement web front-end, notamment la structuration des pages avec HTML,
la mise en forme avec CSS et l'interactivité avec JavaScript, afin de créer une plateforme de commerce électronique moderne, responsive et conviviale.
